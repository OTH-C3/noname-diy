# 官方技能速查

## 用途

用户提出「加〖铁骑〗」「做成〖蛊惑〗那样的技能」时，仅凭技能名不足 —— 需取得官方效果文本。
此前须检索引擎源码，现直接查本库。

适用：引用官方技能效果、为新技能检索同类机制、核对技能名与出处。

## 检索

**按名称**（最常用）：

```sh
grep -n "^### 铁骑" references/skills/技能速查-*.md      # 定位标题
grep -n "当你受到伤害后" references/skills/技能速查-*.md   # 按效果文本
```

**多版本聚合**：同名技能按包分列于同一 `### 名称` 下（如「奸雄」9 版：标准 / 界 / 联动经典曹操 / 线下九鼎曹操…）。

**按类型筛选**：

```sh
grep -B 1 "锁定技" references/skills/技能速查-*.md | head -40
```

## 词条结构

```md
### 奸雄
- **标准 · 曹操** `jianxiong`
  当你受到伤害后，你可以获得对你造成伤害的牌。
- **界 · 界曹操** `new_rejianxiong`
  当你受到伤害后，你可以获得对你造成伤害的牌并摸一张牌。
```

- 加粗：`出处包 · 使用武将`（可含类型标注，如 `· 锁定技`）
- 反引号内：**技能 id** —— 代码中的键（`characters.skills` 数组、`translate` 键、`lib.skill` 键均用它）
- 次行起：描述原文（`〖〗` 内为所引用的其他技能名）

## 已知边界

- **`〖xxx〗` 为技能引用**，多数已解析为中文名；173 处因引擎本身未定义中文名（多见于动态生成的描述）
  保留 id 形式。
- 描述**原文照搬**（`<br>` 已转为换行，`①②` 序号保留）。官方笔误（如「吹奏阶段」）**不改** —— 属原文。
- 仅含**描述**，不含实现代码。实现写法见 `../无名杀技能系统.md` 与 `../无名杀规范.md`：
  本库答「效果是什么」，那两份答「代码怎么写」。
- **非唯一来源，亦非权威**：本库未收录 **≠** 官方不存在（可能仅本机引擎版本未收）。
  未命中时转查引擎源码 `character/**` 或官方线上资料 —— **不得因本库未命中即断言「无此技能」**。

## 重新生成

换引擎版本后重刷。两个脚本在 `scripts/`（与其它工具同处），均为纯标准库：

```sh
# 第一步：从引擎源码提取技能数据 → 中间 JSON
node scripts/extract-skills.mjs <引擎源码根> /tmp/skills_raw.json

# 第二步：整理成分片文档（直接写回本目录，README.md 不会被覆盖）
python3 scripts/build-skill-doc.py /tmp/skills_raw.json references/skills <引擎源码根>
```

**引擎源码根怎么拿**：取官方 release 的 `noname.core.zip`（约 40MB），解压后那个目录就是
（含 `character/*.js` / `game/` / `noname/` / `noname.js`）。**不要 git clone 官方 monorepo**
—— 那边是 `apps/core/character/<包>/translate.js` 的分目录结构，与本脚本要的扁平
`character/*.js` 不同。下载后核对官方提供的 `.sha256`。

GitHub release 直链慢或中断时走镜像（实测 `ghfast.top`、`ghproxy.net`、`gh-proxy.com` 可用）：

```sh
curl -sL -o noname.core.zip \
  "https://ghfast.top/https://github.com/libnoname/noname/releases/download/<tag>/noname.core.zip"
```

- 前者以 `vm` 求值提取全部 `translate` 表（较正则可靠）
- 后者负责清洗、按技能名聚合、分片，并打印统计；分片头部的版本基准写在该脚本里，换版本时一并改
- 第二步的第 3 参数也走环境变量 `DIY_ENGINE_ROOT`；不给则卡牌无法从技能里分出

换版本后重跑即可，无需手改文档。分片文件名是写死的（`技能速查-1..5.md`）——
改片数要同时改脚本里的 `SHARDS`。中间 JSON 可随时删，不影响本目录。
