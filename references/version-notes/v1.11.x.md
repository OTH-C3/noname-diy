## 版本差异与已知坑

| 事项 | 说明 |
|---|---|
| **对象参数 API** | 需要 **v1.11.3+**。老版本上是**静默失效**（不是报错）→ 对外分发优先用旧式位置参数 |
| **`card.js` 的 gaintag 写入** | v1.11.5.2 在第 853 行，官方 v1.11.6 在第 895 行 —— 写法一样，**问题两个版本都在** |
| **扩展目录位置** | 游戏包：`resources/app/extension/`；官方仓库：`apps/core/extension/` |
| **构建产物 vs 源码** | 运行时加载的是 `character/*.js` 构建产物，**改 `src/` 不生效** |
| **新扩展默认关闭** | 放进 `extension/` 后要在游戏「扩展」页手动开启 |

## 写这些地方要格外小心

1. **`event.getParent(4)` 的层数** —— 依赖调用栈深度，**最容易出错**。
   若「造成伤害后却走了没造成伤害的分支」，改 `getParent(3)` 或 `5` 试。
2. **拼点动画崩溃**（症状：`Cannot set properties of null`）—— 对策是 `card.copy()` 的 gaintag 兼容补丁
3. **技能 UI**：标记位置与文字、卜算界面、选牌弹窗
4. **跨角色的牌移动**：`ui.special` / 武将牌上的牌，取回与弃置链路

- 新条目一律**带上核对日期与出处**（源码核对 / 参照官方样例）
- 只写**有出处**的结论，不要把推测混入
- **写进下面的「本机增量」小节**，别改上面的基线条目；基线失效时在新条目里写「推翻 X：…」
  （保留基线原文以便回源对照）

  即使条目顺序变了也仍能对上。
- 更新 skill 走 `scripts/update-skill.py` —— 这一段会被合并保留，不会被整包覆盖冲掉
